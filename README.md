# Chrestys Skatepark — RattleRamp

Tablet kiosk skate game for the U Chřestýše bar next to the skate park: a 2D U-ramp where you swipe tricks as 3×3 patterns and time the release to the coping.

- `Prompts/00-RATTLERAMP_PLAN.md` — design plan (Czech)
- `rattleramp/` — Flutter + Flame app (M0 feel prototype + M1 trick grammar). See `rattleramp/CLAUDE.md`.

```bash
cd rattleramp && flutter test && flutter run
```
